# VoiceBokaroTools
人力ボカロのための声抽出ツール

## 使い方
1. 使いたい音楽や動画を探す
2. 演奏などがある場合は、声だけを抽出する 「[ここ](https://vocalremover.org/ja/)のサイトがおすすめ」
3. 「ffmpeg.exe」を、「C:\ffmpeg\bin\ffmpeg.exe」に設置する
4. 「cut.exe」を実行する
5. 音声を読み込む
6. 画像の設定を、その音声に合わせて変える 「YAJU&Uの場合は、[ここ](/YAJUU.md)を参考にできます。」
7. 必要な素材を選択し、「この区間を再生」を押す
8. その音声が好みなら、「選択区間を MP3 保存」を押し保存する
